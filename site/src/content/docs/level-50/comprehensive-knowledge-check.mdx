This check covers all three Level 50 modules. Most questions describe a short scenario, so they test whether you can apply the ideas, not just recall them. Answer each one, then open the answer to see the reasoning and the page to review. If you get 16 or more right, you're ready for Level 100.

## Cloud computing

### Question 1

A finance team asks why their cloud bill is classed as operational expenditure. What's the best answer?

- A. The provider owns the hardware, so it can't be capital expenditure.
- B. They pay for cloud services as they consume them, over time.
- C. Cloud services are always cheaper than servers.
- D. Operational expenditure is required by cloud contracts.

<KnowledgeCheck answer="B" reference="/level-50/module-01-cloud-computing/cloud-computing-primer/">

Cloud computing uses a consumption-based model, so spending is ongoing and tied to use. That's operational expenditure.

A gives a related fact but not the reason for the classification. C is false; cost depends on how you run workloads. D isn't true.

</KnowledgeCheck>

### Question 2

Which NIST characteristic explains why your VM might run on the same physical server as another customer's VM?

- A. On-demand self-service
- B. Broad network access
- C. Resource pooling
- D. Measured service

<KnowledgeCheck answer="C" reference="/level-50/module-01-cloud-computing/cloud-computing-primer/">

Resource pooling means the provider serves many tenants from one shared pool of hardware. It's also why data location and isolation become design questions.

A is about provisioning without help, B is about reaching services over the network, and D is about metering use.

</KnowledgeCheck>

### Question 3

A company moves its email to Microsoft 365. Under the shared responsibility model, which of these is still the company's job?

- A. Patching the mail server operating system
- B. Managing the physical datacenter
- C. Managing user accounts and who can access mailboxes
- D. Maintaining the physical network

<KnowledgeCheck answer="C" reference="/level-50/module-01-cloud-computing/cloud-service-models/">

Microsoft 365 is SaaS. The customer always keeps responsibility for its data, identities, and access, whatever the service model.

A, B, and D belong to the provider in SaaS.

</KnowledgeCheck>

### Question 4

A hospital keeps patient records in its own datacenter and runs its public website in Azure, with the two connected. Which deployment model is this?

- A. Public cloud
- B. Private cloud
- C. Hybrid cloud
- D. Multicloud

<KnowledgeCheck answer="C" reference="/level-50/module-01-cloud-computing/cloud-deployment-models/">

Hybrid cloud connects a private environment with a public cloud so they work together.

A and B describe only one side. D means two or more public cloud providers.

</KnowledgeCheck>

### Question 5

During a sales event, a web app goes from 3 VMs to 12 VMs and back to 3 afterward. Which concept does this show?

- A. Vertical scaling
- B. Horizontal scaling (scale out and in)
- C. High availability
- D. Region pairing

<KnowledgeCheck answer="B" reference="/level-50/module-01-cloud-computing/cloud-benefits/">

Adding and removing instances is horizontal scaling.

A changes the size of one resource. C is about staying available despite failures. D is about pairs of regions for recovery.

</KnowledgeCheck>

## Security and compliance

### Question 6

An attacker floods a public website with traffic until it stops responding. Which property of the CIA triad is under attack?

- A. Confidentiality
- B. Integrity
- C. Availability
- D. Authentication

<KnowledgeCheck answer="C" reference="/level-50/module-02-security-compliance/security-compliance-basics/">

A distributed denial-of-service attack takes a system offline, so it targets availability.

A is about who can read data. B is about data being changed. D isn't part of the CIA triad.

</KnowledgeCheck>

### Question 7

In the defense-in-depth model, which layer uses DDoS protection and firewalls at the network edge?

- A. Physical security
- B. Perimeter
- C. Compute
- D. Data

<KnowledgeCheck answer="B" reference="/level-50/module-02-security-compliance/security-compliance-basics/">

The perimeter layer filters large-scale attacks with DDoS protection and inspects traffic with perimeter firewalls.

A protects buildings and hardware. C protects VMs and containers. D protects the data itself.

</KnowledgeCheck>

### Question 8

A security architect says, "We design as if an attacker is already inside, so we segment access and monitor everything." Which Zero Trust principle is that?

- A. Verify explicitly
- B. Use least privilege access
- C. Assume breach
- D. Defense in depth

<KnowledgeCheck answer="C" reference="/level-50/module-02-security-compliance/security-compliance-basics/">

Assume breach means limiting the damage an attacker can do once inside, and detecting them quickly.

A is about checking every request. B is about giving minimal access. D is a separate layered model, not a Zero Trust principle.

</KnowledgeCheck>

### Question 9

An older slide lists six Zero Trust pillars. Which pillar does Microsoft's current guidance add as the seventh?

- A. Identities
- B. Data
- C. SecOps
- D. Compliance

<KnowledgeCheck answer="C" reference="/level-50/module-02-security-compliance/security-compliance-basics/">

The seven pillars are Identities, Endpoints, Data, Apps, Infrastructure, Network, and SecOps. SecOps collects signals from the others to detect and respond.

A and B were already among the six. D isn't a Zero Trust pillar.

</KnowledgeCheck>

### Question 10

Which statement best describes data sovereignty?

- A. Data is stored in a specific physical location.
- B. Data is subject to the laws of the country where it's collected, held, or processed.
- C. Data is encrypted at rest.
- D. Data is backed up to a second region.

<KnowledgeCheck answer="B" reference="/level-50/module-02-security-compliance/data-protection-principles/">

Data sovereignty is about which laws apply to data. Data residency, in A, is about where it's stored. The two are related but not the same.

C and D are protection measures, not definitions of sovereignty.

</KnowledgeCheck>

### Question 11

A bank needs to keep its encryption keys in tamper-resistant hardware, separate from its data. What should it use?

- A. A hardware security module, for example through Azure Key Vault
- B. A configuration file next to the application
- C. A hash of the key stored in the database
- D. A shared password in a spreadsheet

<KnowledgeCheck answer="A" reference="/level-50/module-02-security-compliance/data-protection-principles/">

Hardware security modules are built to store and protect keys. Azure Key Vault centralizes keys, secrets, and certificates and controls access to them.

B and D keep keys where an attacker can find them. C doesn't work; you can't recover a key from its hash.

</KnowledgeCheck>

### Question 12

Microsoft groups its compliance offerings into four segments. In which segment is Germany's C5?

- A. Globally applicable
- B. US government
- C. Industry specific
- D. Region or country specific

<KnowledgeCheck answer="D" reference="/level-50/module-02-security-compliance/compliance-frameworks/">

C5 is a German national scheme, so it sits in the region or country specific segment.

A covers offerings such as ISO/IEC 27001. B covers programs such as FedRAMP. C covers offerings such as PCI DSS.

</KnowledgeCheck>

### Question 13

What happened on November 18, 2025, under the EU's Digital Operational Resilience Act (DORA)?

- A. DORA was first proposed.
- B. The European Supervisory Authorities published the list of critical ICT third-party providers, including Microsoft Ireland Operations Limited.
- C. DORA was repealed.
- D. GDPR replaced DORA.

<KnowledgeCheck answer="B" reference="/level-50/module-02-security-compliance/compliance-frameworks/">

On November 18, 2025, the authorities published the list of critical ICT third-party providers. Microsoft Ireland Operations Limited is on it and subject to their direct oversight. DORA itself has applied since January 17, 2025.

A, C, and D didn't happen.

</KnowledgeCheck>

### Question 14

An organization deploys AI agents that act on employee data. Which Microsoft Entra product is built to give those agents governed identities?

- A. Microsoft Entra ID Protection
- B. Microsoft Entra Agent ID
- C. Microsoft Entra Domain Services
- D. Microsoft Entra External ID

<KnowledgeCheck answer="B" reference="/level-50/module-02-security-compliance/identity-access-basics/">

Microsoft Entra Agent ID gives each AI agent an identity, enforces least-privilege access, and keeps an audit trail.

A detects identity risks for users. C provides managed domain services for older apps. D handles partners, guests, and customers.

</KnowledgeCheck>

### Question 15

You assign the Reader role to a group at the subscription scope. What can the group's members do?

- A. Nothing until you also assign Reader on each resource group.
- B. View every resource group and resource in that subscription.
- C. Change every resource in the subscription.
- D. Read the data inside every application.

<KnowledgeCheck answer="B" reference="/level-50/module-02-security-compliance/identity-access-basics/">

Azure RBAC permissions inherit downward, so Reader on a subscription applies to everything in it.

A ignores inheritance. C would need a role such as Contributor. D is wrong because Azure RBAC controls Azure resources, not access to data inside an application.

</KnowledgeCheck>

## Microsoft Azure

### Question 16

A colleague says Azure has "exactly 60 regions." What's the most accurate response?

- A. That's right; Azure has had 60 regions since launch.
- B. The Azure regions list on Microsoft Learn showed 57 named regions when this course was checked. Other Microsoft pages round to "more than 60." The number changes, so check the list.
- C. Azure has 200 regions.
- D. Azure doesn't publish its regions.

<KnowledgeCheck answer="B" reference="/level-50/module-03-azure-intro/azure-global-infrastructure/">

Use 57 as the count from the regions list, and "more than 60" only as a rounded figure. Both change as regions open.

A, C, and D are wrong. Microsoft publishes the full regions list on Microsoft Learn.

</KnowledgeCheck>

### Question 17

How many availability zones do most zone-enabled Azure regions have?

- A. One
- B. Two
- C. Three
- D. Ten

<KnowledgeCheck answer="C" reference="/level-50/module-03-azure-intro/azure-global-infrastructure/">

Every zone-enabled region has at least three availability zones, and most have exactly three. Not every region has zones.

A and B are below the minimum. D doesn't match any region.

</KnowledgeCheck>

### Question 18

Customer records must not leave one country, and the Azure region in that country has no region pair. Which storage redundancy option fits best?

- A. Geo-redundant storage (GRS)
- B. Zone-redundant storage (ZRS)
- C. Read-access geo-redundant storage (RA-GRS)
- D. No redundancy

<KnowledgeCheck answer="B" reference="/level-50/module-03-azure-intro/azure-service-categories/">

ZRS keeps three copies across the region's availability zones and doesn't copy data to a second region. Microsoft recommends it when replication must stay in one country or region.

A and C copy data to a secondary region. D isn't an option; Azure Storage always keeps at least three copies.

</KnowledgeCheck>

### Question 19

A team wants to deploy the same set of Azure resources for development, test, and production, the same way every time. What should they use?

- A. The Azure portal, clicking through each environment
- B. Bicep files stored in source control
- C. Azure Copilot only
- D. Azure Cloud Shell history

<KnowledgeCheck answer="B" reference="/level-50/module-03-azure-intro/azure-management-tools/">

Bicep is declarative infrastructure as code. The same file deploys the same environment every time.

A is manual and easy to get wrong. C can help draft code but doesn't replace a repeatable deployment file. D isn't a deployment method.

</KnowledgeCheck>

### Question 20

A defense customer runs in Azure Government and asks for Azure Copilot. What do you tell them?

- A. It's available in all Azure clouds.
- B. Azure Copilot isn't available in Azure Government or Azure operated by 21Vianet.
- C. It's available only through the Azure CLI there.
- D. It requires a separate Azure Government license.

<KnowledgeCheck answer="B" reference="/level-50/module-03-azure-intro/azure-management-tools/">

Microsoft Learn states that Azure Copilot isn't available in the national clouds. Checking which features exist in which cloud is a routine step in sovereign designs.

A is false. C and D describe options that don't exist.

</KnowledgeCheck>
