This module covers the security and compliance ideas that every later level assumes you know. It follows the Microsoft Learn security, compliance, and identity fundamentals and stays vendor-neutral where it can, with Microsoft products as examples. Sovereignty adds requirements on top of these basics, such as who holds the keys and who can operate the platform. Level 100 picks up from there.
