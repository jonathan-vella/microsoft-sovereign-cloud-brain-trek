## Question 1

An attacker changes the bank account number on a supplier invoice in your finance system. Which property of the CIA triad did the attacker break?

- A. Confidentiality
- B. Integrity
- C. Availability
- D. Accountability

<KnowledgeCheck answer="B" reference="/level-50/module-02-security-compliance/security-compliance-basics/">

Integrity means data changes only through authorized processes. An unauthorized edit is an integrity violation.

A would apply if the attacker only read the invoice. C would apply if the finance system went offline. D isn't one of the three CIA properties.

</KnowledgeCheck>

## Question 2

In the defense-in-depth model on Microsoft Learn, which layer sits at the center, protected by all the others?

- A. Physical security
- B. Identity and access
- C. Network
- D. Data

<KnowledgeCheck answer="D" reference="/level-50/module-02-security-compliance/security-compliance-basics/">

Data is the innermost layer, because data is what attackers are after. The other six layers (physical security, identity and access, perimeter, network, compute, application) surround it.

A is the outermost layer. B and C are outer layers that protect the layers inside them.

</KnowledgeCheck>

## Question 3

Which list contains the three Zero Trust principles?

- A. Verify explicitly, use least privilege access, assume breach
- B. Confidentiality, integrity, availability
- C. Identify, assess, respond
- D. Trust the network, verify users, monitor devices

<KnowledgeCheck answer="A" reference="/level-50/module-02-security-compliance/security-compliance-basics/">

Zero Trust rests on three principles: verify explicitly, use least privilege access, and assume breach.

B is the CIA triad. C is part of the risk management cycle. D contradicts Zero Trust, which never trusts a request because of its network location.

</KnowledgeCheck>

## Question 4

How many technology pillars does Microsoft's current Zero Trust guidance use, and which pillar ties the others together?

- A. Five, with Network at the center
- B. Six, with Identities at the center
- C. Seven, with SecOps integrating signals from the other six
- D. Eight, with Data at the center

<KnowledgeCheck answer="C" reference="/level-50/module-02-security-compliance/security-compliance-basics/">

The seven pillars are Identities, Endpoints, Data, Apps, Infrastructure, Network, and SecOps. SecOps (called visibility, automation, and orchestration in the security fundamentals module) collects signals from the other six to detect and respond to threats.

B reflects older material that listed six pillars. A and D don't match Microsoft's guidance.

</KnowledgeCheck>

## Question 5

Which encryption protects data while a VM processes it in memory?

- A. Encryption at rest
- B. Encryption in transit
- C. Encryption in use, through confidential computing
- D. Hashing

<KnowledgeCheck answer="C" reference="/level-50/module-02-security-compliance/data-protection-principles/">

Data is normally decrypted when it's loaded into memory. Confidential computing processes it in a protected hardware environment that even the operating system and hypervisor can't read.

A protects stored data. B protects data moving across a network. D is one-way and can't be reversed to process the data.

</KnowledgeCheck>

## Question 6

Why should encryption keys be stored apart from the data they protect?

- A. It makes encryption faster.
- B. An attacker who gets the data shouldn't automatically get the key as well.
- C. Regulations forbid storing keys in the cloud.
- D. Keys are too large to store with data.

<KnowledgeCheck answer="B" reference="/level-50/module-02-security-compliance/data-protection-principles/">

Encryption only helps if the key stays secret. Keeping keys in a separate service, such as Azure Key Vault or a hardware security module, means a stolen copy of the data stays unreadable.

A is false; separation doesn't change speed. C is false as a general rule. D is false; keys are small.

</KnowledgeCheck>

## Question 7

Microsoft groups its compliance offerings into four segments. Which list is correct?

- A. Public, private, hybrid, multicloud
- B. Globally applicable, US government, industry specific, region or country specific
- C. Identity, data, network, compute
- D. Free, basic, standard, premium

<KnowledgeCheck answer="B" reference="/level-50/module-02-security-compliance/compliance-frameworks/">

The compliance offerings page groups offerings as globally applicable (for example ISO/IEC 27001), US government (for example FedRAMP), industry specific (for example PCI DSS), and region or country specific (for example Germany C5).

A lists deployment models. C mixes Zero Trust pillars and defense-in-depth layers. D isn't a compliance grouping.

</KnowledgeCheck>

## Question 8

Your application runs on Azure services that are ISO/IEC 27001 certified. What does that mean for your own compliance?

- A. Your application is automatically ISO/IEC 27001 certified.
- B. You inherit the platform's controls for the in-scope services, but you're still responsible for your own compliance.
- C. You no longer need to configure security.
- D. Nothing; provider certifications don't apply to customers.

<KnowledgeCheck answer="B" reference="/level-50/module-02-security-compliance/compliance-frameworks/">

Provider certifications cover the provider's side of the shared responsibility model, and you can use their audit reports as evidence. Microsoft states that you're wholly responsible for your own compliance.

A and C overstate what a provider certification covers. D understates it; inherited controls and audit reports do help you.

</KnowledgeCheck>

## Question 9

Under GDPR, which role does Microsoft take when it processes personal data in its online services for you?

- A. Data controller
- B. Data processor
- C. Supervisory authority
- D. Data subject

<KnowledgeCheck answer="B" reference="/level-50/module-02-security-compliance/compliance-frameworks/">

Microsoft acts as a data processor. You're the controller: you decide why and how personal data is processed.

A is your role. C is a public authority that enforces GDPR. D is the person the data is about.

</KnowledgeCheck>

## Question 10

Which sign-in method uses a hardware device, needs no password, and resists phishing?

- A. Password with security questions
- B. SMS one-time code
- C. FIDO2 security key
- D. Single sign-on

<KnowledgeCheck answer="C" reference="/level-50/module-02-security-compliance/identity-access-basics/">

FIDO2 security keys are passwordless hardware authenticators. With no password to type, there's nothing for a phishing site to steal.

A is password-based. B is a second factor used alongside a password, so it isn't passwordless. D lets you sign in once for many apps, but it's only as strong as that first sign-in.

</KnowledgeCheck>

## Question 11

A user signs in from a new country on an unmanaged laptop. Conditional Access requires MFA before granting access. Which Zero Trust principle does this apply most directly?

- A. Verify explicitly
- B. Assume breach
- C. Defense in depth
- D. Shared responsibility

<KnowledgeCheck answer="A" reference="/level-50/module-02-security-compliance/identity-access-basics/">

Conditional Access evaluates signals (location, device, risk) for each request and then decides. That's "verify explicitly" in practice.

B is about limiting damage once an attacker is inside. C and D are security models, not Zero Trust principles.

</KnowledgeCheck>

## Question 12

Your company deploys AI agents that read customer data on behalf of employees. Which Microsoft Entra product gives each agent its own governed identity with least-privilege access and an audit trail?

- A. Microsoft Entra Domain Services
- B. Microsoft Entra Verified ID
- C. Microsoft Entra Agent ID
- D. Microsoft Entra Internet Access

<KnowledgeCheck answer="C" reference="/level-50/module-02-security-compliance/identity-access-basics/">

Microsoft Entra Agent ID extends Entra identity, authorization, governance, and protection to AI agents.

A provides managed domain services for older applications. B issues verifiable credentials to people. D secures access to internet resources.

</KnowledgeCheck>
