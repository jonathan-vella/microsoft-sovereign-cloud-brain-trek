## Question 1

Which list contains the three cloud service models?

- A. Public, private, hybrid
- B. IaaS, PaaS, SaaS
- C. Compute, storage, networking
- D. Basic, standard, premium

<KnowledgeCheck answer="B" reference="/level-50/module-01-cloud-computing/cloud-service-models/">

IaaS, PaaS, and SaaS are the service models defined in NIST SP 800-145. They describe how much of the stack the provider runs.

A lists deployment models, which describe where resources run. C lists service categories. D looks like pricing tiers.

</KnowledgeCheck>

## Question 2

You run SQL Server on an Azure virtual machine. Who patches the guest operating system?

- A. Microsoft, because the VM runs in Azure
- B. You, because the VM is IaaS
- C. Nobody, because cloud VMs don't need patches
- D. Microsoft and you share it equally

<KnowledgeCheck answer="B" reference="/level-50/module-01-cloud-computing/cloud-service-models/">

In IaaS the provider is responsible for the physical hosts, network, datacenter, and hypervisor. You're responsible for the operating system and everything above it.

A would be true for PaaS, such as Azure SQL Database. C is false: every operating system needs updates. D is wrong because the operating system isn't a shared area in IaaS.

</KnowledgeCheck>

## Question 3

Which responsibilities stay with the customer in every service model, including SaaS?

- A. Physical hosts and physical network
- B. Operating system and network controls
- C. Customer data, and identities and users
- D. The hypervisor

<KnowledgeCheck answer="C" reference="/level-50/module-01-cloud-computing/cloud-service-models/">

The customer always owns customer data, configurations and settings, and identities and users, whatever the service model.

A and D belong to the provider in every cloud model. B moves to the provider in PaaS (operating system) and SaaS (both).

</KnowledgeCheck>

## Question 4

What is the main difference between a public cloud and a private cloud?

- A. A public cloud is free and a private cloud is paid.
- B. A public cloud is available to anyone who buys the service. A private cloud is used by a single organization.
- C. A public cloud can't be secured.
- D. A private cloud always runs in the customer's own building.

<KnowledgeCheck answer="B" reference="/level-50/module-01-cloud-computing/cloud-deployment-models/">

The defining difference is who can use the infrastructure: anyone in a public cloud, one organization in a private cloud.

A is false; public cloud is pay-as-you-go. C is false; security is a shared responsibility in both. D is false; a private cloud can also run in a dedicated offsite datacenter operated by a third party.

</KnowledgeCheck>

## Question 5

A company uses Azure for its web shop and a second public cloud provider for analytics. Which deployment model is this?

- A. Private cloud
- B. Hybrid cloud
- C. Multicloud
- D. Community cloud

<KnowledgeCheck answer="C" reference="/level-50/module-01-cloud-computing/cloud-deployment-models/">

Multicloud means using two or more public cloud providers.

A and B both need a private cloud, which this company doesn't have. Hybrid connects public and private clouds. D isn't one of the models in the Microsoft Learn fundamentals path.

</KnowledgeCheck>

## Question 6

A VM is running out of memory. You resize it from 4 GB to 16 GB of RAM. What kind of scaling is this?

- A. Horizontal scaling (scale out)
- B. Vertical scaling (scale up)
- C. Elastic pooling
- D. Load balancing

<KnowledgeCheck answer="B" reference="/level-50/module-01-cloud-computing/cloud-benefits/">

Vertical scaling changes the size of a resource, such as adding CPUs or memory.

A changes the number of resources, for example from 2 VMs to 5. C isn't a scaling type. D spreads traffic across resources but doesn't add capacity.

</KnowledgeCheck>

## Question 7

Why is cloud computing classed as operational expenditure (OpEx)?

- A. You buy the servers up front and depreciate them.
- B. You pay for services as you consume them.
- C. The provider owns the operating system.
- D. Cloud services have no fixed costs.

<KnowledgeCheck answer="B" reference="/level-50/module-01-cloud-computing/cloud-computing-primer/">

OpEx is ongoing spending on services over time. The consumption-based model bills you as you use resources, so cloud spending is OpEx.

A describes capital expenditure (CapEx). C is unrelated to how spending is classified. D is false; some services and commitments have fixed monthly charges.

</KnowledgeCheck>

## Question 8

Which NIST characteristic lets you create a VM from a portal at 2 a.m. without contacting the provider?

- A. Broad network access
- B. Resource pooling
- C. On-demand self-service
- D. Measured service

<KnowledgeCheck answer="C" reference="/level-50/module-01-cloud-computing/cloud-computing-primer/">

On-demand self-service means you provision resources yourself, through a portal or API, with no human interaction with the provider.

A is about reaching the service over the network. B is about the provider sharing hardware across tenants. D is about metering and billing what you use.

</KnowledgeCheck>

## Question 9

Which Azure service lets you manage servers and Kubernetes clusters in your own datacenter and in other clouds from the Azure portal?

- A. Azure VMware Solution
- B. Azure Arc
- C. Azure App Service
- D. Microsoft 365

<KnowledgeCheck answer="B" reference="/level-50/module-01-cloud-computing/cloud-deployment-models/">

Azure Arc projects resources outside Azure into Azure Resource Manager, so you can manage and govern them with Azure tools.

A runs VMware workloads inside Azure; it doesn't manage resources in other clouds. C is a PaaS service for hosting web apps. D is a SaaS productivity suite.

</KnowledgeCheck>

## Question 10

A regulator requires that certain records never run on hardware shared with other organizations. Which factor should drive the deployment model choice first?

- A. Number of employees
- B. Data sensitivity and regulatory requirements
- C. Location of the head office
- D. Age of the existing servers

<KnowledgeCheck answer="B" reference="/level-50/module-01-cloud-computing/cloud-deployment-models/">

Regulatory and data-sensitivity requirements rule options in or out before cost and convenience. Here they point to a private cloud, or a hybrid design that keeps those records private.

A and C don't decide where data may run. D affects migration timing, not which model is allowed.

</KnowledgeCheck>
