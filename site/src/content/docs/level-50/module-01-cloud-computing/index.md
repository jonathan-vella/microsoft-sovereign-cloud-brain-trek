This module covers the cloud vocabulary that the rest of the course depends on. It's vendor-neutral, and it follows the cloud concepts in the Microsoft Learn Azure Fundamentals path. If you already know IaaS, PaaS, SaaS, and the shared responsibility model, try the knowledge check first.
