This module applies the cloud and security concepts from Modules 1 and 2 to Microsoft Azure. It follows the Azure Fundamentals learning path on Microsoft Learn and adds the points that matter later for sovereignty: which cloud and region you deploy to, where copies of your data live, and which features exist in which cloud.
