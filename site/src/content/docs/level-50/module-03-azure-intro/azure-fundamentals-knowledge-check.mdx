## Question 1

Which order is correct, from the broadest scope to the narrowest?

- A. Resource group, subscription, management group, resource
- B. Management group, subscription, resource group, resource
- C. Subscription, management group, resource, resource group
- D. Resource, resource group, subscription, management group

<KnowledgeCheck answer="B" reference="/level-50/module-03-azure-intro/microsoft-azure-overview/">

Management groups hold subscriptions, subscriptions hold resource groups, and resource groups hold resources. Policies and access set at one level apply to everything below it.

A and C mix up the levels. D is the right order but reversed, from narrowest to broadest.

</KnowledgeCheck>

## Question 2

A team creates a test environment in one resource group. What happens when they delete the resource group?

- A. Only the empty resource group is removed.
- B. All resources in the resource group are deleted.
- C. The resources move to the subscription's default resource group.
- D. Azure blocks the deletion until each resource is deleted first.

<KnowledgeCheck answer="B" reference="/level-50/module-03-azure-intro/microsoft-azure-overview/">

Actions on a resource group apply to everything in it. Deleting the group deletes all its resources, which makes cleanup of temporary environments simple.

A, C, and D don't match how resource groups work. There's no default resource group that catches orphaned resources.

</KnowledgeCheck>

## Question 3

How many named regions does the Azure regions list on Microsoft Learn show for the global public cloud, as checked for this course?

- A. 23
- B. 42
- C. 57
- D. 120

<KnowledgeCheck answer="C" reference="/level-50/module-03-azure-intro/azure-global-infrastructure/">

The regions list showed 57 named regions when this course was checked in October 2026. Other Microsoft pages round it to "more than 60." The number changes as regions open, so check the list before you quote it.

A, B, and D don't match the list.

</KnowledgeCheck>

## Question 4

What is an availability zone?

- A. A single server rack in a datacenter
- B. A group of one or more physically separate datacenters within a region, with independent power, cooling, and networking
- C. A second region in the same geography
- D. A content delivery location at the network edge

<KnowledgeCheck answer="B" reference="/level-50/module-03-azure-intro/azure-global-infrastructure/">

An availability zone is an isolation boundary inside a region. If one zone fails, the others keep running. Regions that support zones have at least three, and most have exactly three.

A is far smaller than a zone. C describes a paired region. D describes an edge location, not a zone.

</KnowledgeCheck>

## Question 5

A workload must keep all its data inside one Azure region for legal reasons. What does Microsoft recommend to maximize its availability?

- A. Replicate it to the paired region in another country.
- B. Deploy it across availability zones in that region, and add backups.
- C. Use locally redundant storage only.
- D. Nothing; a single-region workload can't be made more available.

<KnowledgeCheck answer="B" reference="/level-50/module-03-azure-intro/azure-global-infrastructure/">

For workloads limited to one region by data residency or sovereignty rules, Microsoft recommends a zone-resilient design. It keeps every copy in the region and survives the loss of one zone. Backups cover a full-region outage.

A breaks the legal requirement. C keeps all copies in one datacenter, so it doesn't survive a zone failure. D is false.

</KnowledgeCheck>

## Question 6

Which statement about region pairs is true?

- A. Every Azure region has a pair.
- B. Deploying to a paired region gives you automatic disaster recovery.
- C. Some newer regions, such as Italy North and Poland Central, have no pair and rely on availability zones.
- D. Region pairs are always in different geographies.

<KnowledgeCheck answer="C" reference="/level-50/module-03-azure-intro/azure-global-infrastructure/">

Many newer regions have no region pair and use availability zones for resilience.

A is false for those regions. B is false; only some services use the pair, and you still need your own recovery plan. D is false; pairs are almost always in the same geography.

</KnowledgeCheck>

## Question 7

You want to run a single container quickly without managing virtual machines or a Kubernetes cluster. Which service fits best?

- A. Azure Virtual Machines
- B. Azure Kubernetes Service
- C. Azure Container Instances
- D. Azure Virtual Desktop

<KnowledgeCheck answer="C" reference="/level-50/module-03-azure-intro/azure-service-categories/">

Azure Container Instances is the fastest and simplest way to run a container in Azure, with no VMs or orchestration to manage.

A needs you to manage a VM. B is for orchestrating a fleet of containers. D delivers desktops, not containers.

</KnowledgeCheck>

## Question 8

Which Azure Storage redundancy option keeps three copies of data across three availability zones in one region, without copying to a second region?

- A. Locally redundant storage (LRS)
- B. Zone-redundant storage (ZRS)
- C. Geo-redundant storage (GRS)
- D. Geo-zone-redundant storage (GZRS)

<KnowledgeCheck answer="B" reference="/level-50/module-03-azure-intro/azure-service-categories/">

ZRS replicates data synchronously across three zones in the primary region. Microsoft recommends it when data must stay in one country or region.

A keeps all three copies in one datacenter. C and D also copy data to a secondary region.

</KnowledgeCheck>

## Question 9

You need to store backups that are almost never read and can wait several hours to be restored, at the lowest storage cost. Which blob access tier fits?

- A. Hot
- B. Cool
- C. Cold
- D. Archive

<KnowledgeCheck answer="D" reference="/level-50/module-03-azure-intro/azure-service-categories/">

The archive tier has the lowest storage cost, a 180-day minimum, and retrieval measured in hours.

A is for data in active use. B (30-day minimum) and C (90-day minimum) are online tiers for data you need immediately, at a higher storage cost than archive.

</KnowledgeCheck>

## Question 10

Which tool gives you a browser-based, already-authenticated terminal with the Azure CLI and Azure PowerShell preinstalled?

- A. Azure portal dashboards
- B. Azure Cloud Shell
- C. Bicep
- D. Azure Arc

<KnowledgeCheck answer="B" reference="/level-50/module-03-azure-intro/azure-management-tools/">

Cloud Shell runs in the browser, signs you in automatically, and lets you choose Bash or PowerShell.

A is a graphical view, not a terminal. C is a language for infrastructure as code. D brings resources outside Azure under Azure management.

</KnowledgeCheck>

## Question 11

Why would a team use Bicep instead of creating resources by hand in the portal?

- A. Bicep is the only way to create VMs.
- B. Bicep files declare the end state, so the same environment deploys the same way every time.
- C. Bicep bypasses Azure Resource Manager and is faster.
- D. Bicep can only deploy storage accounts.

<KnowledgeCheck answer="B" reference="/level-50/module-03-azure-intro/azure-management-tools/">

Bicep is declarative infrastructure as code. You describe what you want, store it in source control, and get repeatable deployments.

A is false; every tool can create VMs. C is false; Bicep deploys through Azure Resource Manager like every tool. D is false; Bicep supports every Azure resource type.

</KnowledgeCheck>

## Question 12

A public sector customer runs its workloads in Azure Government. Can its administrators use Azure Copilot there?

- A. Yes, Azure Copilot is available in every Azure cloud.
- B. No, Azure Copilot isn't available in Azure Government or Azure operated by 21Vianet.
- C. Yes, but only in English.
- D. Only through the Azure CLI.

<KnowledgeCheck answer="B" reference="/level-50/module-03-azure-intro/azure-management-tools/">

Microsoft Learn states that Azure Copilot isn't available in the national clouds: Azure Government and Azure operated by 21Vianet. This is a common gap to check in sovereign designs.

A is false. C and D describe options that don't exist; in global Azure, Azure Copilot works in the portal and the Azure mobile app, in 19 languages.

</KnowledgeCheck>
