Microsoft Sovereign Cloud is a portfolio of deployment models for organizations that need stronger control over data location, operations, access, and local governance. The portfolio is no longer called Microsoft Cloud for Sovereignty in current Microsoft Learn pages.

This module introduces the three Microsoft Sovereign Cloud deployment models at Level 100 depth. Start with the shared comparison, then read the page for the model that matches the customer requirement you are testing.
