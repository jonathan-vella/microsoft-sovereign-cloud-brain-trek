Use these questions to check whether you can distinguish the three Microsoft Sovereign Cloud deployment models and their main controls.

### Question 1: Portfolio name

What is the current portfolio name for the offering formerly called Microsoft Cloud for Sovereignty?

- A) Azure Government
- B) Microsoft Sovereign Cloud
- C) Azure Stack Sovereignty
- D) Microsoft Cloud Boundary

<KnowledgeCheck answer="B" reference="/level-100/module-02-cloud-models/sovereign-cloud-models/">

B is correct because Microsoft Learn now uses Microsoft Sovereign Cloud for the portfolio. A is wrong because Azure Government is a separate US government cloud environment. C and D are not current Microsoft portfolio names.

</KnowledgeCheck>

### Question 2: Three models

Which set matches the three Microsoft Sovereign Cloud deployment models?

- A) Azure Government, Azure China, Azure Germany
- B) Public, hybrid, multicloud
- C) Sovereign Public Cloud, Sovereign Private Cloud, National Partner Clouds
- D) Azure Local, Azure Arc, Microsoft 365 Local

<KnowledgeCheck answer="C" reference="/level-100/module-02-cloud-models/sovereign-cloud-models/">

C is correct because the current portfolio has those three deployment models. A lists legacy or separate cloud environments, not the current model set. B uses generic cloud terms. D lists components, not the three deployment models.

</KnowledgeCheck>

### Question 3: Terminology trap

Why must you clarify the phrase "Azure sovereign clouds" when reading older material?

- A) It may refer to legacy isolated Azure environments rather than the current Microsoft Sovereign Cloud portfolio.
- B) It always means National Partner Clouds.
- C) It always means Azure Local disconnected operations.
- D) It is the current name for Sovereign Control Panel.

<KnowledgeCheck answer="A" reference="/level-100/module-02-cloud-models/sovereign-cloud-models/">

A is correct because older material can use "Azure sovereign clouds" for environments such as Azure Government or Azure operated by 21Vianet. B and C narrow the term incorrectly. D is wrong because Sovereign Control Panel is a public-cloud posture tool, not a cloud model.

</KnowledgeCheck>

### Question 4: Public-cloud fit

A customer can run in Azure public regions, but must enforce data residency, key control, operator access oversight, and policy. Which model should you evaluate first?

- A) Sovereign Public Cloud
- B) Sovereign Private Cloud
- C) National Partner Clouds
- D) GitHub Enterprise Local

<KnowledgeCheck answer="A" reference="/level-100/module-02-cloud-models/sovereign-public-cloud/">

A is correct because Sovereign Public Cloud adds sovereignty controls to Azure public-cloud regions. B is for customer-operated infrastructure. C is for partner-operated national clouds. D is a private-cloud DevOps component, not a deployment model.

</KnowledgeCheck>

### Question 5: Public-cloud capabilities

Which list contains the four named Sovereign Public Cloud capabilities on Microsoft Learn?

- A) Data Guardian, External Key Management, Azure confidential computing, Sovereign Control Panel
- B) Azure Arc, Azure Local, Azure Monitor, Azure Policy
- C) Customer Lockbox, Azure Firewall, Azure Bastion, ExpressRoute
- D) Microsoft 365 Local, GitHub Enterprise Local, Foundry Local, Agentic Retrieval

<KnowledgeCheck answer="A" reference="/level-100/module-02-cloud-models/sovereign-public-cloud/">

A is correct. Microsoft Learn lists Data Guardian, External Key Management, confidential computing, and Sovereign Control Panel. B and C include useful Azure services but not the four named capabilities. D lists private-cloud components and an AI retrieval capability.

</KnowledgeCheck>

### Question 6: Sovereign Control Panel name

What was Sovereign Control Panel formerly called?

- A) Customer Lockbox
- B) Regulated Environment Management
- C) Sovereign Landing Zone
- D) Azure Policy Baseline

<KnowledgeCheck answer="B" reference="/level-100/module-02-cloud-models/sovereign-public-cloud/">

B is correct because Microsoft Learn states that Regulated Environment Management is now Sovereign Control Panel. A is a support-access approval workflow. C is a landing-zone pattern. D is not the former product name.

</KnowledgeCheck>

### Question 7: Customer Lockbox scope

Which statement about Customer Lockbox is most accurate?

- A) It applies to every Microsoft cloud service without exception.
- B) It is broad, but coverage and carve-outs vary by service.
- C) It replaces Azure Policy for data residency.
- D) It stores customer-managed keys outside Microsoft.

<KnowledgeCheck answer="B" reference="/level-100/module-02-cloud-models/sovereign-public-cloud/">

B is correct because Microsoft Learn lists many covered services and also documents preview areas and carve-outs. A overstates coverage. C is wrong because Azure Policy enforces configuration rules. D describes key-control patterns, not Customer Lockbox.

</KnowledgeCheck>

### Question 8: Private-cloud components

Which set belongs to Sovereign Private Cloud?

- A) Azure Local, Microsoft 365 Local, GitHub Enterprise Local, Foundry Local on Azure Local
- B) Bleu, Delos Cloud, SecNumCloud, German Cloud Platform Requirements
- C) EU Data Boundary, Data Guardian, External Key Management, Sovereign Control Panel
- D) Azure Government, Azure operated by 21Vianet, Azure Government Secret, Azure Government Top Secret

<KnowledgeCheck answer="A" reference="/level-100/module-02-cloud-models/sovereign-private-cloud/">

A is correct because Microsoft Learn lists those components for Sovereign Private Cloud. B describes National Partner Cloud examples and targets. C lists public-cloud controls. D lists separate Azure cloud environments, not the current private-cloud component set.

</KnowledgeCheck>

### Question 9: Disconnected operations

Which status statement is correct for disconnected operations?

- A) Azure Local disconnected operations are generally available with Azure Local 2602 or later, while AKS on Azure Local with disconnected operations is preview.
- B) Azure Local disconnected operations and AKS on Azure Local disconnected operations are both retired.
- C) AKS on Azure Local disconnected operations are generally available, but Azure Local disconnected operations are preview.
- D) Disconnected operation is only available in National Partner Clouds.

<KnowledgeCheck answer="A" reference="/level-100/module-02-cloud-models/sovereign-private-cloud/">

A is correct. Azure Local disconnected operations are generally available with Azure Local 2602 or later, and AKS on Azure Local with disconnected operations remains preview. B and C reverse or invent the status. D is wrong because disconnected operation is a private-cloud pattern.

</KnowledgeCheck>

### Question 10: GitHub Enterprise Local

What is the current status and purpose of GitHub Enterprise Local?

- A) It is generally available and replaces GitHub.com for every Azure customer.
- B) It is preview and runs GitHub Enterprise Server as a self-hosted DevOps platform on Azure Local.
- C) It is retired and replaced by Azure DevOps Server.
- D) It is a National Partner Cloud for software development.

<KnowledgeCheck answer="B" reference="/level-100/module-02-cloud-models/sovereign-private-cloud/">

B is correct. Microsoft Learn marks GitHub Enterprise Local as preview and describes it as GitHub Enterprise Server on Azure Local. A overstates status and scope. C is wrong because the Learn page is current. D is wrong because it is a private-cloud component, not a partner cloud.

</KnowledgeCheck>

### Question 11: National Partner Cloud examples

Which pairing is correct?

- A) Bleu in Italy and Delos Cloud in France
- B) Bleu in France and Delos Cloud in Germany
- C) Delos Cloud in Italy and Bleu in Germany
- D) Azure Germany in France and Azure China in Germany

<KnowledgeCheck answer="B" reference="/level-100/module-02-cloud-models/national-partner-clouds/">

B is correct. Bleu is the France partner cloud with Orange and Capgemini, and Delos Cloud is the Germany partner cloud operated by an SAP subsidiary. A and C place the clouds in the wrong countries. D lists unrelated or retired environments.

</KnowledgeCheck>

### Question 12: National Partner Cloud status

Which statement should you use for Bleu and Delos Cloud at Level 100?

- A) Both are still being built, and service scope can differ from global Azure.
- B) Both are generally available in every Azure region.
- C) Bleu is the Italy partner cloud and Delos Cloud is the France partner cloud.
- D) Both replace Sovereign Private Cloud for disconnected operation.

<KnowledgeCheck answer="A" reference="/level-100/module-02-cloud-models/national-partner-clouds/">

A is correct. Microsoft Learn describes current National Partner Cloud examples that are still being built, and it warns that service scope and rollout can differ from global Azure. B invents general availability and global reach. C uses the wrong countries. D confuses partner-operated cloud with customer-operated disconnected environments.

</KnowledgeCheck>
