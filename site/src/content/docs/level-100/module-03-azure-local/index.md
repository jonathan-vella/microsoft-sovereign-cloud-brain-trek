Azure Local runs Azure-consistent infrastructure on hardware that your organization owns or operates. In Sovereign Private Cloud, it provides the local compute, storage, networking, and management foundation for workloads that need jurisdictional control, local latency, intermittent connectivity, or fully disconnected operation.

This module focuses on current Azure Local facts. You learn the release train, support window, deployment types, connected and disconnected operating models, hardware catalog categories, and the workload choices that matter most at Level 100.
