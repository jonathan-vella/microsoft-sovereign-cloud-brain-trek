### Question 1: Arc control plane

Which statement best describes Azure Arc?

- A) Azure Arc migrates non-Azure workloads into Azure.
- B) Azure Arc projects supported non-Azure resources into Azure Resource Manager for management and governance.
- C) Azure Arc replaces all local infrastructure management tools.
- D) Azure Arc is only for Azure Local clusters.

<KnowledgeCheck answer="B" reference="/level-100/module-04-azure-arc/azure-arc-intro/">

B is correct because Arc gives supported resources Azure identities, resource IDs, tags, policies, and extensions while they keep running where they are. A is wrong because migration is a separate activity. C is wrong because local operations tools still matter. D is wrong because Arc also supports servers, Kubernetes clusters, SQL, data services, and private cloud resources beyond Azure Local.

</KnowledgeCheck>

### Question 2: Arc pricing

What is the correct pricing statement for Azure Arc?

- A) Core Arc control-plane features are free, and services layered on top bill at their own rates.
- B) Every Arc-connected server has a fixed monthly Arc license fee.
- C) Azure Monitor and Microsoft Defender for Cloud become free when enabled through Arc.
- D) Arc billing replaces all Windows Server and SQL Server licensing.

<KnowledgeCheck answer="A" reference="/level-100/module-04-azure-arc/azure-arc-intro/">

A is correct because Microsoft lists baseline Arc control-plane features at no extra charge, while services such as Monitor, Defender for Cloud, and Arc-enabled SQL Managed Instance follow their own pricing. B is wrong because there is no fixed core Arc server fee. C is wrong because those services can bill separately. D is wrong because product licensing remains separate unless a specific Arc licensing option applies.

</KnowledgeCheck>

### Question 3: Arc gateway status

Which statement about Arc gateway is current?

- A) It is generally available for Arc-enabled servers and Azure Local infrastructure, and preview for AKS on Azure Local.
- B) It is preview for every Arc resource type.
- C) It removes all outbound connectivity requirements.
- D) It is required for Azure Arc resource bridge.

<KnowledgeCheck answer="A" reference="/level-100/module-04-azure-arc/azure-arc-intro/">

A is correct because Microsoft documents Arc gateway as generally available for Arc-enabled servers and Azure Local infrastructure and VMs, while AKS on Azure Local support remains preview. B is wrong because some support is already generally available. C is wrong because gateway reduces required endpoints but still uses outbound Azure connectivity. D is wrong because resource bridge and gateway are different components.

</KnowledgeCheck>

### Question 4: Arc resource bridge platforms

Which private cloud platforms does Azure Arc resource bridge support?

- A) VMware vSphere, Azure Local, and System Center Virtual Machine Manager.
- B) Only Azure Local.
- C) Azure VMware Solution, Azure Kubernetes Service, and Azure Virtual Desktop.
- D) Any hypervisor without version or platform limits.

<KnowledgeCheck answer="A" reference="/level-100/module-04-azure-arc/azure-arc-intro/">

A is correct because Microsoft lists VMware vSphere, Azure Local, and System Center Virtual Machine Manager as supported private clouds for Arc resource bridge. B is wrong because Azure Local is not the only supported platform. C lists Azure services rather than the private cloud platforms named for resource bridge. D is wrong because support is platform and version specific.

</KnowledgeCheck>

### Question 5: Windows Server licensing

What does Windows Server pay-as-you-go through Azure Arc provide?

- A) Azure-billed Windows Server licensing for Windows Server 2025 and later.
- B) Free Windows Server licenses for every Arc-enabled machine.
- C) SQL Server licensing through Azure Monitor.
- D) A way to run Windows Server without Azure connectivity or billing.

<KnowledgeCheck answer="A" reference="/level-100/module-04-azure-arc/azure-arc-servers/">

A is correct because Microsoft documents Windows Server pay-as-you-go through Arc for Windows Server 2025 and later, billed through Azure. B is wrong because it is a paid licensing model, not a free license. C is wrong because SQL Server licensing is a different product area. D is wrong because the model depends on Azure billing through Arc.

</KnowledgeCheck>

### Question 6: Windows Server Management benefit

Which capability is part of Windows Server Management enabled by Azure Arc?

- A) Update Manager and Machine Configuration for eligible Windows Server machines.
- B) Automatic migration of servers to Azure virtual machines.
- C) Guaranteed disconnected operation for every Arc feature.
- D) Replacement of local administrator accounts.

<KnowledgeCheck answer="A" reference="/level-100/module-04-azure-arc/azure-arc-servers/">

A is correct because Microsoft includes capabilities such as Update Manager, Change Tracking, Machine Configuration, Windows Admin Center, and related management benefits. B is wrong because migration is not the purpose of the benefit. C is wrong because ordinary Arc features still depend on their documented connectivity model. D is wrong because local access and operating system administration remain part of server operations.

</KnowledgeCheck>

### Question 7: Arc-enabled Kubernetes scope

Which Kubernetes clusters can Azure Arc connect?

- A) Any CNCF-certified Kubernetes cluster, subject to prerequisites and supported features.
- B) Only AKS clusters running in Azure public regions.
- C) Only Kubernetes clusters that use Microsoft container images.
- D) Only clusters that run on VMware vSphere.

<KnowledgeCheck answer="A" reference="/level-100/module-04-azure-arc/azure-arc-kubernetes/">

A is correct because Microsoft describes Arc-enabled Kubernetes as working with any CNCF-certified Kubernetes cluster. B is wrong because Arc can connect clusters outside Azure. C is wrong because workload image choice is not the defining support rule. D is wrong because VMware is only one possible infrastructure location.

</KnowledgeCheck>

### Question 8: AKS on Azure Local relationship

How should you describe AKS on Azure Local with Arc in a sovereign design?

- A) AKS on Azure Local uses Arc for Azure management, but disconnected operations for AKS on Azure Local remain preview.
- B) AKS on Azure Local is unrelated to Azure Arc.
- C) AKS on Azure Local disconnected operations are generally available for Kubernetes.
- D) Arc gateway for AKS on Azure Local has the same generally available status as Arc-enabled servers.

<KnowledgeCheck answer="A" reference="/level-100/module-04-azure-arc/azure-arc-kubernetes/">

A is correct because Arc is the Azure management connection for AKS on Azure Local, and Microsoft labels AKS on Azure Local disconnected operations as preview. B is wrong because Arc is part of the management model. C is wrong because disconnected Kubernetes support is not generally available. D is wrong because Arc gateway for AKS on Azure Local is still preview.

</KnowledgeCheck>

### Question 9: Arc data services retirements

Which statement is current for Azure Arc data services?

- A) Azure Arc-enabled PostgreSQL server retired on July 14, 2025, and indirectly connected mode retired in September 2025.
- B) PostgreSQL Hyperscale on Arc and indirect mode are recommended for disconnected sovereign designs.
- C) Indirect mode is required for SQL Managed Instance enabled by Azure Arc.
- D) Arc data services no longer include SQL Managed Instance.

<KnowledgeCheck answer="A" reference="/level-100/module-04-azure-arc/azure-arc-data-services/">

A is correct because Microsoft release notes list the PostgreSQL retirement and the September 2025 indirect mode retirement. B is wrong because both PostgreSQL on Arc and indirect mode are retired. C is wrong because direct mode is now the supported mode. D is wrong because SQL Managed Instance enabled by Azure Arc remains active.

</KnowledgeCheck>

### Question 10: SQL options through Arc

Which distinction is correct?

- A) SQL Server enabled by Azure Arc connects existing SQL Server instances, while SQL Managed Instance enabled by Azure Arc is an Arc data services managed instance pattern on Kubernetes.
- B) SQL Server enabled by Azure Arc and SQL Managed Instance enabled by Azure Arc are the same service.
- C) SQL Server enabled by Azure Arc requires the retired indirect data services mode.
- D) SQL Managed Instance enabled by Azure Arc is retired because PostgreSQL retired.

<KnowledgeCheck answer="A" reference="/level-100/module-04-azure-arc/azure-arc-data-services/">

A is correct because SQL Server enabled by Azure Arc manages existing SQL Server instances on Windows or Linux hosts, while SQL Managed Instance enabled by Azure Arc is part of Arc data services on Kubernetes. B is wrong because the services have different deployment models. C is wrong because SQL Server enabled by Azure Arc uses the server agent and SQL extension model, not retired indirect mode. D is wrong because SQL Managed Instance enabled by Azure Arc is not retired.

</KnowledgeCheck>
