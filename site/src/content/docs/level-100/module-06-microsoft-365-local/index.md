Microsoft 365 Local brings selected Microsoft productivity server workloads into a customer-owned private cloud. In this module, you learn what Microsoft includes in Microsoft 365 Local, why Azure Local is the infrastructure base, and how connected and disconnected operation affect sovereignty planning.

The module stays at a foundation level. It focuses on scope, architecture, deployment constraints, and the business-continuity pattern Microsoft documents for Microsoft 365 Local.
