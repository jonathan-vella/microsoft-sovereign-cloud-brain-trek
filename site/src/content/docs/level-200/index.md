Level 200 is for architects and pre-sales engineers who already know what Microsoft Sovereign Cloud is and now need
to design and size a solution. Each module turns the Level 100 concepts into planning decisions: which Azure Local
deployment type fits, how to govern servers and Kubernetes with Azure Arc, what Foundry Local on Azure Local needs,
which controls answer a regulator's question, and how to size and price the result.

Plan for roughly 8 to 12 hours. Each module ends with a knowledge check.

## What you can do after this level

- Choose an Azure Local deployment type and connectivity model from a customer's scale, site, and sovereignty
  requirements.
- Plan Azure Arc governance, policy, and cost for servers and Kubernetes across on-premises and other clouds.
- Plan a Foundry Local on Azure Local and Agentic Retrieval deployment, including GPUs and Kubernetes prerequisites.
- Run a discovery workshop, size a solution, and build a cost model without guessing prices.
- Map GDPR, NIS2, DORA, and FedRAMP requirements to Microsoft tools and controls.
- Explain the Sovereign Public Cloud controls and the Sovereign Private Cloud stack, and when to use each.

## Before you start

Complete [Level 100](/level-100/), or be able to explain the three Microsoft Sovereign Cloud deployment models, the
difference between connected and disconnected Azure Local, and what Azure Arc does.

Several products covered here change often. The modules cite the status of each one on the page where it's used.
