## Question 1: Arc gateway fit

A customer uses an enterprise proxy and wants to reduce the number of public outbound FQDNs required for Azure Arc-enabled servers. The proxy team also wants to audit Arc agent traffic. Which option best fits?

- A) Use Azure Arc gateway.
- B) Use Azure Arc resource bridge.
- C) Use Azure Update Manager.
- D) Use SQL Managed Instance enabled by Azure Arc in indirect mode.

<KnowledgeCheck answer="A" reference="/level-200/module-02-arc/arc-advanced-management/">

A is correct because Arc gateway reduces the server endpoint list to seven FQDNs and lets teams audit Arc traffic. B is wrong because resource bridge is for private cloud VM management. C is wrong because Update Manager handles patch assessment and deployment. D is wrong because indirect mode for Azure Arc-enabled data services is retired.

</KnowledgeCheck>

## Question 2: TLS inspection

A network team requires all outbound traffic to pass through a proxy that terminates and inspects TLS. What should the Arc architect tell them about Arc gateway?

- A) Arc gateway replaces TLS and makes inspection unnecessary.
- B) Arc gateway is recommended only when the proxy can terminate nested TLS.
- C) Arc gateway is not recommended for TLS termination or inspection, and the gateway endpoint should skip TLS inspection.
- D) Arc gateway requires Private Link before TLS inspection can work.

<KnowledgeCheck answer="C" reference="/level-200/module-02-arc/arc-advanced-management/">

C is correct because Microsoft says Arc gateway is not recommended where TLS termination or inspection is required and recommends skipping inspection for the gateway endpoint. A is wrong because Arc gateway does not replace TLS. B is wrong because nested TLS termination is outside standard terminating proxy behavior. D is wrong because Private Link is a separate connectivity option.

</KnowledgeCheck>

## Question 3: Azure Local gateway status

A platform team wants to use Arc gateway for a new Azure Local deployment and for AKS on Azure Local workloads. Which status statement is correct?

- A) Both Azure Local infrastructure and AKS on Azure Local gateway support are retired.
- B) Azure Local infrastructure and Azure Local VMs are generally available for Arc gateway, while AKS on Azure Local remains in preview.
- C) AKS on Azure Local is generally available for Arc gateway, while Azure Local VMs remain in preview.
- D) Arc gateway can be enabled after any existing Azure Local deployment.

<KnowledgeCheck answer="B" reference="/level-200/module-02-arc/arc-advanced-management/">

B is correct because Microsoft states that Arc gateway for Azure Local infrastructure and Azure Local VMs is generally available, while Arc gateway for AKS on Azure Local is still in preview. A and C reverse or invent the status. D is wrong because the Azure Local gateway article says it is enabled during new deployments for supported versions, not after deployment.

</KnowledgeCheck>

## Question 4: Resource bridge use case

An enterprise wants application teams to create and manage VMware vSphere VMs from Azure while central operations keeps vCenter as the local fabric. What Azure Arc component is required?

- A) Machine configuration.
- B) Azure Arc resource bridge.
- C) Azure Policy extension for Kubernetes.
- D) Azure Arc gateway only.

<KnowledgeCheck answer="B" reference="/level-200/module-02-arc/arc-advanced-management/">

B is correct because Arc resource bridge projects supported private cloud resources, including VMware vSphere 7.0 and 8.0, into Azure for VM lifecycle operations. A manages guest settings. C applies Kubernetes policy through Gatekeeper. D can simplify connectivity but does not provide VM lifecycle management.

</KnowledgeCheck>

## Question 5: Resource bridge lifecycle

Which operating practice keeps Azure Arc resource bridge inside the support window?

- A) Upgrade only during major Azure Local releases.
- B) Upgrade at least once every six months and stay within the latest n-3 versions.
- C) Replace it with Private Link after 90 days.
- D) Disable version tracking because Microsoft performs all upgrades automatically.

<KnowledgeCheck answer="B" reference="/level-200/module-02-arc/arc-advanced-management/">

B is correct because Microsoft recommends staying within the last six months or latest n-3 versions and says the appliance must still be upgraded at least every six months. A is too infrequent and tied to the wrong product cadence. C is wrong because resource bridge does not support Private Link. D is wrong because cloud-managed upgrades do not replace the need for regular upgrades.

</KnowledgeCheck>

## Question 6: Machine configuration scope

A security team needs to audit and, later, autocorrect local operating system settings on Arc-enabled Windows and Linux servers. Which capability should they use?

- A) Azure Policy machine configuration.
- B) Azure Arc gateway.
- C) Azure Resource Graph only.
- D) Azure Policy extension for Arc-enabled Kubernetes.

<KnowledgeCheck answer="A" reference="/level-200/module-02-arc/arc-policy-and-governance/">

A is correct because machine configuration audits or configures operating system settings as code on Azure and Arc-enabled machines. B is for connectivity. C can query resources but does not configure the operating system. D governs Kubernetes components such as pods, containers, and namespaces.

</KnowledgeCheck>

## Question 7: Kubernetes policy behavior

A cluster already has a pod that violates a new deny policy assigned through Azure Policy for Kubernetes. What happens immediately after the assignment?

- A) The existing pod is always deleted automatically.
- B) The existing pod can continue running, but Gatekeeper can block it when it is recreated or rescheduled.
- C) The policy extension cannot report the violation to Azure Policy.
- D) Azure Policy requires replacing Gatekeeper with a Microsoft-only admission controller.

<KnowledgeCheck answer="B" reference="/level-200/module-02-arc/arc-policy-and-governance/">

B is correct because existing non-compliant resources can continue running, while Gatekeeper blocks creation when the resource is recreated or rescheduled. A is wrong because the policy does not always delete existing pods. C is wrong because the extension reports compliance to Azure Policy. D is wrong because Azure Policy extends Gatekeeper.

</KnowledgeCheck>

## Question 8: Connectivity choice

A regulated customer wants Arc-enabled server traffic to reach Azure Arc over ExpressRoute or site-to-site VPN by using private endpoints rather than public networks. Which connectivity option is the better fit?

- A) Arc gateway.
- B) Azure Private Link for Arc-enabled servers.
- C) Azure Arc resource bridge.
- D) Windows Server pay-as-you-go.

<KnowledgeCheck answer="B" reference="/level-200/module-02-arc/arc-enterprise-patterns/">

B is correct because Private Link for Arc-enabled servers routes traffic through private endpoints over private network connectivity. A reduces public outbound FQDNs but still uses public cloud connectivity. C supports private cloud VM projection. D is a licensing model.

</KnowledgeCheck>

## Question 9: Cost boundary

A finance team asks why a connected Arc server has Azure charges when Arc control-plane capabilities are offered at no extra cost. What is the best answer?

- A) Azure Arc always charges per connected server.
- B) Azure Arc charges only when the server is not tagged.
- C) The Arc control plane can be free while linked services such as Azure Monitor, Defender for Cloud, Sentinel, Update Manager, machine configuration, or Private Link incur their own charges.
- D) Charges mean the server was connected through the wrong region.

<KnowledgeCheck answer="C" reference="/level-200/module-02-arc/arc-cost-optimization/">

C is correct because Arc control-plane functions can be included while layered Azure services bill according to their usage. A is wrong because the pricing page lists no-cost control-plane capabilities. B is wrong because tags do not create billing exemptions. D is wrong because region choice alone does not explain linked service charges.

</KnowledgeCheck>

## Question 10: Data services retirement

A solution design still proposes indirectly connected mode for SQL Managed Instance enabled by Azure Arc and includes Arc-enabled PostgreSQL server. What should be changed?

- A) Keep both because they are required for disconnected sites.
- B) Use direct connectivity for SQL Managed Instance enabled by Azure Arc and remove Arc-enabled PostgreSQL server because it retired in July 2025.
- C) Replace SQL Managed Instance enabled by Azure Arc with Grafana and OpenSearch dashboards.
- D) Use Arc gateway to restore indirect mode.

<KnowledgeCheck answer="B" reference="/level-200/module-02-arc/arc-advanced-management/">

B is correct because Azure Arc-enabled data services support direct connectivity mode, indirect mode is retired for SQL Managed Instance enabled by Azure Arc, and Arc-enabled PostgreSQL server retired in July 2025. A keeps retired items. C is wrong because those dashboards were removed for Arc-enabled SQL Managed Instance. D is wrong because Arc gateway does not restore a retired data services connectivity mode.

</KnowledgeCheck>
