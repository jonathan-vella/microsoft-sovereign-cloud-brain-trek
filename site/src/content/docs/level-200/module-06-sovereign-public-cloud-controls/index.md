Sovereign Public Cloud lets regulated organizations use Microsoft-operated hyperscale cloud regions with added controls for data residency, operational oversight, customer-controlled encryption, and evidence collection ([Learn](https://learn.microsoft.com/azure/azure-sovereign-clouds/public/overview-sovereign-public-cloud)). This module focuses on the public cloud controls that are current for Microsoft Sovereign Cloud.

You learn how the EU Data Boundary, Data Guardian, Customer Lockbox, Managed HSM, External Key Management, confidential computing, Sovereign Control Panel, and Azure Policy work together. Treat these controls as a design set. A workload rarely needs every control, but the control choice must match the legal, contractual, and assurance requirement.
